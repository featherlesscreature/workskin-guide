# Local Testing
By downloading all of the stylesheets used by ao3, you can create a test environment that resembles ao3. This seems to work properly, but it has not been tested with all css elements, so it is possible there are some differences between the local environment and ao3.

## Easy Setup
To help with setup, there is a [github repository](https://github.com/featherlesscreature/workskin-tester) that provides all the stylesheets, and an HTML page setup to use them.
